# Ten Ten maison

Talkie-walkie entre amis : même code de groupe = on s'entend. Une seule page web, aucun serveur à héberger.

## Utiliser
Ouvre https://charlie6194lou.github.io/tenten/ dans Safari, puis Partager > « Sur l'écran d'accueil ».
Entre ton pseudo et le code du groupe, autorise le micro, maintiens le bouton pour parler.

## Comment ça marche
- La page est hébergée gratuitement par GitHub Pages (ce dépôt).
- Les messages vocaux passent par ntfy.sh, un relais public et gratuit, sans compte.
  Le code du groupe est transformé en nom de canal secret : choisis un code pas devinable.
- ntfy.sh garde les messages vocaux quelques heures au maximum, puis les efface.

## Limites
- Il faut que l'appli soit ouverte à l'écran pour entendre (un site web ne peut pas jouer de son quand il est fermé sur iPhone).
- Si tu n'es pas connecté quand un ami parle, tu ne l'entends pas.
- La liste des amis montre ceux qui ont eu l'appli ouverte dans les 2 dernières minutes.
